Mildly Apocalyptic Uploader

This is a private tool used only by the owner of the YouTube channel Mildly Apocalyptic to manage that one channel.

It uses the YouTube Data API and YouTube Analytics API to:

  • upload and schedule the channel's own videos,
  • post and reply to comments on the channel's own videos,
  • read view counts and analytics for the channel's own videos.

It is not offered to other users and does not access anyone else's account.
