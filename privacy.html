Privacy Policy

Last updated: November 24, 2026

Mildly Apocalyptic Uploader is a private tool used only by the owner of the YouTube channel Mildly Apocalyptic. It is not available to the public.

What data the app uses

With the owner's permission (Google OAuth), the app accesses the owner's own YouTube channel through the YouTube Data API and YouTube Analytics API: the channel's videos, comments on those videos, and the channel's view statistics.

How the data is used

The data is used only to upload and schedule the channel's videos, post and reply to comments on the channel's own videos, and measure how the channel's videos perform. The app does not use the data for advertising.

Storage and sharing

Access tokens and any data the app reads are stored only on the owner's own computer. The data is not sold, shared with or transferred to third parties.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy).

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
